1.3.0，新功能都在设置里

从自己的小目标，到每天的工作节奏，让鼓励器更贴近你的习惯。

Personal Goals

每个目标，都有自己的样子

添加、修改或删除目标，为它选择 Emoji、颜色与本地图片封面。置顶、拖拽或上下移动，按你的顺序展示。

Celebration

点亮目标，轻轻庆祝

轻量动画、系统通知或静默，随你选择。每日小目标与每月心愿分别去重，重新打开不会重复庆祝。

Calendar

班表也能灵活调整

按日期手动标记放假、补班、提前下班与当天休息时段。计薪、倒计时、时间轴随当天安排一起变化。

Menu Bar

菜单栏，八种显示方式

收入、剩余金额、下班倒计时、今日进度、目标进度与所需工时，还能随工作状态自动切换。

Reminders

到点休息，也记得下班

午休、晚饭、下班与定时活动提醒集中管理。设置允许提醒时间和跨午夜免打扰，通知不显示薪资金额。

Mini Window

把小小进度放在手边

可拖动的原生迷你悬浮窗，支持置顶和透明度调整。显示收入、下班倒计时或置顶目标的进度。

Native Comfort

更顺手的原生操作

开机自动启动、⌘⇧E / ⌃⌥E 全局快捷键、记住上次页面，以及手动检查 GitHub 正式版本。

Local Backup

你的设置，随时带走

完整 JSON 备份保留薪资、班表与偏好；仅目标备份不含薪资。导入先检查、再确认替换。

Companion

橘猫和小芽，陪你一会儿

可选动态伙伴，随着工作、休息、下班改变状态。点一下，给自己一句鼓励；也可以随时关闭。

One Settings Page

把想调整的，都放在同一个地方。

点击面板右上角的滑杆图标，进入设置。主题、隐私、目标、日历、提醒、悬浮窗、启动方式与备份都有清晰的分组。

  • 保留深色、浅色、跟随系统与一键金额打码。
  • 目标和单日班表点击保存生效，其余偏好即时保存。
  • 原有设置继续保留，无需重新填写薪资和目标。
  • “关于”包含版本、项目链接和贡献者 Feng Wang · @caseclose。

通知、开机启动和快捷键按需开启；系统权限以 macOS 实际授权状态为准。网页中不可用的原生选项会禁用。

透明的计薪与折算逻辑

按你设置的班表估算进度，午休、晚饭期间暂停累加。单日临时班表仍按固定日薪折算，短班改变当天计薪速度：

每天计薪分钟 = (下班 − 上班) − 午休时长 − 晚饭时长
每日预计收入 = 月薪 ÷ 每月工作日
每分钟收入   = 每日预计收入 ÷ 每天计薪分钟
今天已挣金额 = 每分钟收入 × 今天已计薪分钟（精确到秒）

大件心愿是本月收入的等价进度，并非实际储蓄余额。个人薪资、班表、目标与封面保存在本机；手动检查更新仅请求 GitHub 版本信息。

安装与源码构建

  1. macOS 13 或更新版本：Apple Silicon 与 Intel 共用一个安装包。下载 Universal .dmg 安装包，将 上班鼓励器.app 拖入 Applications。
  2. 首次打开提示：此版本采用本地签名，尚未经过 Apple 公证。确认从本仓库下载后，可在 macOS「系统设置 → 隐私与安全性」中允许打开。
  3. 从源码一键编译启动：
git clone https://github.com/caseclose/work-encourager-open.git
cd work-encourager-open
npm run start:mac
