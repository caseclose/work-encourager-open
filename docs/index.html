透明的计薪与折算逻辑

只按你真正付出的计薪时间拆解每一分钟的价值，休息时间不稀释单价，但休息期间暂停累加：

每天计薪分钟 = (下班 − 上班) − 午休时长 − 晚饭时长
每日预计收入 = 月薪 ÷ 每月工作日
每分钟收入   = 每日预计收入 ÷ 每天计薪分钟
今天已挣金额 = 每分钟收入 × 今天已计薪分钟（精确到秒）

安装与源码构建

  1. 免编译直接安装：下载 Universal .dmg 安装包，将 上班鼓励器.app 拖入 Applications。
  2. 首次打开提示：若遇到 macOS 未签名提示，在终端运行一次：
    xattr -cr /Applications/上班鼓励器.app
  3. 从源码一键编译启动：
git clone https://github.com/caseclose/work-encourager-open.git
cd work-encourager-open
npm run start:mac
